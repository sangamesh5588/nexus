> **Nexus GenAI** is a multimodal AI workspace application powered by the **Google GenAI SDK (`@google/genai`)**, **React 19**, **Vite 6**, and **Tailwind CSS v4**. It features intelligent contextual prompts, streaming text generation, and fluid GPU-accelerated motion interfaces.

---

## ✨ Features

- ⚡ **Google GenAI SDK Integration:** Direct access to Gemini multimodal vision and reasoning models.
- 🎨 **React 19 & Tailwind CSS v4:** Zero-runtime styling with modern concurrent transitions and streaming state.
- 🎭 **Fluid Motion UI:** Micro-interactions and response streaming animations powered by Motion.

---

## 🚀 Quick Start
```bash
git clone https://github.com/sangamesh5588/nexus.git
cd nexus
npm install
npm run dev
```
